# Atlas visual references and accepted result

The first four files are user-supplied concept/reference images from this task.
They are art-direction inputs, not runtime textures or proof of implemented
geometry. The user chose the compact footprint and the cohesive armor language.

- `industrial-base-reference.png`: original material, track and mounting target.
- `cohesive-armor-reference.png`: joined shell, access-panel seams and skirt design.
- `armor-and-suspension-closeups.png`: folded glacis, protected lights, skirt and running gear.
- `in-game-fidelity-reference.png`: desired material richness at arena distance.

The following are actual Godot captures produced in this task:

- `v4-separated-panel-checkpoint.png`: technically validated material checkpoint;
  construction subsequently rejected as too many separated/floating panels.
- `approved-v5-native-hero.png` and `approved-v5-native-rear.png`: final compact
  cohesive V5 asset. Design approved by the user on 22 September 2026; final
  technical passes completed on 23 September local time.
- `approved-v5-native-foundry.png`: assembled Atlas with its lifter and side armor
  in the unmodified production Foundry. This is an engine review capture, not a
  screenshot of the supplied concept or a hosted-play certification.
