# Atlas MX drive configurations — source renders

Review renders written by `tools/build-atlas-drives.py` (Blender Cycles, AgX
studio) with the approved hull imported and its tracks hidden. They are source
reviews of the authored GLB, not in-game captures; native Godot captures come
from `battlebots/tests/presentation/atlas_drives_showcase.tscn`.

- `drives_wheels_*`: large off-road wheels (`standard_wheels`).
- `drives_legs_*`: hydraulic legs (`walker`) in a mid-stride pose.

Record and validation: [docs/coordination/ATLAS_DRIVES.md](../../docs/coordination/ATLAS_DRIVES.md).
