# Source texture credits

These source maps are bundled so the Blender material build is reproducible.
They are CC0 assets, recolored and combined with authored edge damage and scuffs.

- **Green Metal Rust**, Rob Tuytel / Poly Haven:
  https://polyhaven.com/a/green_metal_rust
  4K diffuse, OpenGL normal and roughness JPG maps.
- **Rusty Painted Metal**, Amal Kumar / Poly Haven:
  https://polyhaven.com/a/rusty_painted_metal
  4K diffuse JPG; only surface variation is used, with broad corrugation bands
  normalized out. No corrugated geometry is applied to the robot.
