# Armour and weapon direction — user sketch, 22 September 2026

The attached sketch is a design reference for the next B combat and build
iteration. It does not change current damage rules or catalogue entries.

Ideas to evaluate with playtests:

- A protected core with four directional side plates, a top plate, and an
  optional underside plate. Choose whether plates share a material or may be
  configured individually. A ramp could trade front protection for speed.
- Light, standard and heavy plate choices affect mass, speed, impulse response
  and core exposure. The current four-side package and 120 kg construction
  budget need an explicit migration before adding top/bottom slots.
- Two compatible weapon sockets could support combinations such as ramp and
  hammer. Define socket limits, power/mass budgets and primary/secondary input
  before changing the catalogue.
- Test piercing and explosive cannon roles, forward spikes, vertical and
  horizontal saws against separate armour and core effects. Decide if and how
  ranged ammunition fits the existing minigun and battery systems.
- Make wheels, walking legs and tracks distinct through traction, terrain
  climbing, stability and collision response. The suggested Ctrl crouch for
  legs needs its own control and network contract if selected for implementation.

The next design pass should first settle plate geometry, damage routing and
mass/impulse formulas, then prototype one build combination against the current
1v1 acceptance checks. No balance value in the sketch is treated as settled.
